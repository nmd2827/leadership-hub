Sources & Updates

Every date here comes from one of two verified sources — nothing is added from memory or guesswork:

  • Waterbury Public Schools 2026–27 District Calendar (BOE-approved PDF) — parent conferences, early dismissals, Winter Recess.
  • Band upcoming-dates handout (in the Digital Band Binder) — Wednesday practices, pep rally, Winter Concert, district performance.

This page is a static snapshot, not a live feed — it does not sync with Outlook or any calendar app. Mr. Drabik updates the agenda by hand when dates change, so if something here disagrees with the district calendar PDF, the district calendar wins.
